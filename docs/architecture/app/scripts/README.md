# Deployment Scripts

This directory contains scripts used to configure, deploy, and maintain the SIGMA web application on AWS.

## Planned Scripts

- `deploy.sh` — deploy application updates to the target EC2 instance
- `health-check.sh` — verify that the application is responding
- `install-dependencies.sh` — install required server packages

## Usage and Safety

Scripts will be tested before use. AWS credentials and private keys must never be stored in this repository.

Scripts will be added as the deployment architecture is implemented and verified.
